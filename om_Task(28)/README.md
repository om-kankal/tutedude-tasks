# Task 28 - ReactJS Router DOM

## Overview
A simple React application demonstrating navigation between four routes with `react-router-dom`.

## Routes
- `/` - Home
- `/dashboard` - Dashboard
- `/login` - Login
- `/signup` - Sign Up

A fallback 404 route is also included.

## Features
- Uses `BrowserRouter`, `Routes` and `Route`
- Uses `Link` and `NavLink` for navigation
- Active navigation link styling
- Simple responsive design
- Separate dashboard and form pages

## Run
1. Open the project folder in a terminal.
2. Run `npm install`.
3. Run `npm start`.
4. Open the address shown by React.

The project uses remote Unsplash images, so internet access is needed for the photos.
