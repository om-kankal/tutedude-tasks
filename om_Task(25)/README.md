# Task 25 - ReactJS Hooks Shoe Store

## Overview
A simple React shoe store demonstrating the React `useState` hook for managing a shopping cart.

## Features
- Displays a collection of shoes with name, price and image.
- Add items to the cart.
- Increase item quantity.
- Decrease quantity and remove an item when its quantity reaches zero.
- Calculates and displays the cart total.
- Responsive layout for smaller screens.

## Files
- `public/index.html`
- `src/App.js`
- `src/index.js`
- `src/style.css`
- `package.json`

## Run
1. Install Node.js.
2. Open the project folder in a terminal.
3. Run `npm install`.
4. Run `npm start`.
5. Open the local address shown by React.

The app uses remote Unsplash image URLs, so an internet connection is needed to display the product photos.
