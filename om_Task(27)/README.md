# Task 27 - ReactJS Custom Hooks

## Overview
This project demonstrates a reusable custom React hook named `useFetch`.

The hook accepts a URL and returns:
- `data` - fetched API data
- `loading` - whether the request is still running
- `error` - an error message when the request fails

## What the app does
The app uses `useFetch` with the JSONPlaceholder photos API and displays the returned photos in a responsive grid.

## Files
- `public/index.html`
- `src/App.js`
- `src/index.js`
- `src/useFetch.js`
- `src/style.css`
- `package.json`

## Run
1. Open the project folder in a terminal.
2. Run `npm install`.
3. Run `npm start`.
4. Open the local address shown in the terminal.

An internet connection is needed to fetch the API data.
