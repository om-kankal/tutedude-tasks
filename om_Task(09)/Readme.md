# Laundry Service Landing Page

This is a simple Laundry Service landing page made using HTML and CSS.

## What I made

The page has:

- A logo
- Navigation links
- A username section
- A hero section with text
- A Book a Service button
- A laundry service image
- Responsive layouts for smaller screens

## Button Hover Effect

The main part of this task was to use CSS transform properties on the button.

I used:

transform: scale(1.05) rotate(-3deg);


When I hover over the button, it becomes slightly bigger and rotates a little.

I also used:


transition: transform 0.3s;


This makes the transform effect smoother.

## Responsive Design

I used media queries for:

* Screens below 768px
* Screens below 480px

On mobile screens, the hero section changes from a horizontal layout to a vertical layout.

The navigation links are hidden on smaller mobile screens.

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Make sure `index.html` and `style.css` are in the same folder.
4. Open `index.html` in a browser.
5. Hover over the Book a Service button.
6. Resize the browser window to check the responsive layout.
