# Laundry Services

A responsive landing page for a laundry service.

The purpose of this project is to create a simple landing page that
works properly on desktop, tablet, and mobile screen sizes while
demonstrating the basic principles of responsive web design.

---

## Project Overview

The page contains:

- A navigation bar
- Laundry service logo
- Navigation links
- Username/profile badge
- Hero heading
- Description
- Call-to-action button
- Laundry-related image

The design uses a two-column layout on larger screens and changes to
a single-column layout on smaller screens.
