# Thala 7 Sneaker Store

This is my CSS mini project for a sneaker selling website.
I made different pages for the website.
## Pages
- Home page
- Product page
- Shopping cart page
- Payment page
## What I used
I used HTML and CSS for this project.
I used Flexbox and Grid to arrange the content.
I also used media queries to make the pages work on smaller screens.
## Product Page
The product page shows the shoe image, product name, price, quantity and Add to Cart button.
## Shopping Cart
The cart page shows products, quantity and price.
It also has coupon, subtotal, tax, discount and total sections.
## Payment
The payment page has email, card, crypto and bank options.
It also has card number, expiry, CVC, country and ZIP fields.
The right side shows the order summary.
