# Task 23 - Project Workspace Hero Page

This submission is the corrected Project Workspace hero page.

## Main file

`index.html`

The entire page layout is written directly in `index.html` and uses the Tailwind CSS CDN. No custom CSS file is required.

## Requirements included

- Sticky navbar using `sticky top-0 z-50`
- Logo text: `✦ Project`
- Navbar links: Product, Solutions, Resources, Pricing and Log in
- `Get AI free` CTA in the navbar
- Hero background with a light orange-to-white gradient
- Centered hero content
- Headline:
  - `Write, plan, share.`
  - `With AI at your side.`
- Description paragraph
- Hero CTAs:
  - `Get AI free`
  - `Request a demo`
- Relative dashboard preview container
- Dashboard preview image positioned inside the relative parent
- Three floating cards using absolute positioning and z-index:
  - Tasks — `12 tasks completed today`
  - Project Status — `On Track`
  - Team Activity — `+5 online`
- Shadows and spacing on the floating cards
- Fixed chat widget using `fixed bottom-6 right-6 z-50`
- Mobile navigation menu
- Responsive layout

## Run

Open `index.html` directly in the browser.

Internet access is needed because Tailwind CSS is loaded using the CDN.
