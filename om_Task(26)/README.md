# Task 26 - ReactJS Props

## Overview
This React project demonstrates passing card information as props to a reusable `Card` component.

## What is included
- Six cards created from an array of objects
- Reusable `Card` component
- `image`, `title`, and `description` passed as props
- Gradient border around every card
- Responsive three-column, two-column and one-column layout
- Simple hover effect

## Files
- `public/index.html`
- `src/App.js`
- `src/index.js`
- `src/style.css`
- `package.json`

## Run the project
1. Open the project folder in a terminal.
2. Run `npm install`.
3. Run `npm start`.
4. Open the local React address in your browser.

The product images use remote Unsplash URLs, so internet access is needed for the images.
