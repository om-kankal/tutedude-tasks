# Task 22 - Tailwind Hero Landing Page

## Project overview
A responsive hero landing page for a modern AI-powered digital workspace, built from the assignment requirements using Tailwind CSS.

## Files
- `index.html` - complete page
- `assets/dashboard.svg` - dashboard preview used in the hero
- `README.md` - project notes

## How to run
Open `index.html` in a browser. The page loads Tailwind CSS from the CDN.

## Requirements covered
- Sticky top navigation using `sticky top-0 z-50`
- Project logo text and navigation links
- "Get AI free" CTA
- Gradient hero background
- Large headline and description
- Two horizontally aligned CTA buttons
- Relative dashboard container with absolute floating cards
- Three floating information cards
- Fixed chat button using `fixed bottom-6 right-6 z-50`
- Responsive layout for desktop, tablet and mobile
- No custom CSS framework required
