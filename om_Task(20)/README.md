# Laundry Services Web App

This is a simple laundry service website made using HTML, CSS and JavaScript.
The website has a navigation bar with Home, Services, About Us and Contact Us.
The hero section contains information about the laundry service.
The Book a service today! button takes the user to the services section.
I added an achievements section to show laundry services, customers and experience.
Different laundry services are displayed with their prices.
Users can click Add Item to add a service to the cart.
After adding a service, the button changes to Remove Item.
Users can remove the service by clicking the Remove Item button.
The added services are displayed in the Added Items section.
The total amount is calculated automatically.
A booking form is provided for Full Name, Email ID and Phone Number.
JavaScript checks that at least one service is selected before booking.
EmailJS is used to send the booking details.
A confirmation message is displayed after successful booking.
I added a section showing Premium Services, Quick Support, Hassle Free Delivery and Affordable Prices.
A newsletter section is included for users to enter their name and email.
The footer contains important links, contact details and social media icons.
CSS media queries are used to make the website responsive on smaller screens.
