# OmniFood Responsive Landing Page - Task 21

## Project overview
A responsive single-page food delivery landing page made with plain HTML and CSS. The page follows the assignment screenshots with a hero banner, How It Works section, city cards, testimonials, pricing cards and footer.

## How to run
Open `index.html` directly in any modern browser.

## Responsive breakpoints
- Desktop: full-width layout with 4 city cards and 3-column pricing/testimonials.
- Tablet: grids reduce to 2 columns.
- Mobile: navigation becomes a CSS hamburger menu and content stacks to one column where needed.

## Files
- `index.html` - page structure
- `style.css` - layout, styling and responsive rules
- `assets/` - local SVG images and icons used by the page
