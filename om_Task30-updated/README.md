# Task 30 - ReactJS Mini Project: Chess

## Overview
An offline two-player chess game made with React.

## Features
- 8x8 chess board with pieces in their starting positions
- Legal movement for pawns, rooks, knights, bishops, queens and kings
- Turn-based play: White and Black alternate turns
- Check and checkmate detection
- Stalemate detection
- Castling
- En passant
- Pawn promotion to queen
- Five-minute countdown timer for each player
- Move list using chess-style square notation
- Reset / New Game button
- Responsive layout for smaller screens

## Files
- `public/index.html`
- `src/App.js`
- `src/chess.js` - chess board setup, move validation and rules
- `src/index.js`
- `src/style.css`
- `package.json`

## How to run
1. Install Node.js.
2. Open the project folder in a terminal.
3. Run `npm install`.
4. Run `npm start`.
5. Open the local address shown by React.

No chess library is used for the game logic.
