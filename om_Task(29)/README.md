# Task 29 - ReactJS Context API

## Overview
This project extends a shoe store with a payment flow using React Context API for shared shopping cart state.

## Main requirements covered
- `CartContext` stores the shopping cart state.
- `useCart` provides cart data and actions to components.
- Users can add shoes to the cart.
- Users can increase or decrease quantities.
- Total price updates automatically.
- "Proceed to Payment" navigates to the payment page.
- Payment page reads the same cart through Context API.
- Users can continue shopping and change cart quantities from the payment page.
- Credit card form is included.
- Demo payment submission shows an order confirmation.

## Run
1. Open the project folder in a terminal.
2. Run `npm install`.
3. Run `npm start`.
4. Open the local React URL in your browser.

This is a frontend demonstration only. No real payment is processed.

Product images are loaded from Unsplash URLs and require an internet connection.
