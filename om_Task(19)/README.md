# Service Booking Web App

This is a simple Service Booking Web App made using HTML, CSS, and JavaScript.
In this project, users can browse different services and add them to their list.
The added services are displayed in the Added Items section.
The total amount updates automatically when a new service is added.
Users can also skip a service and view the next available service.
The Add Item button is used to add the selected service.
The Skip Item button is used to move to another service.
I also added a booking form where the user enters their name, email, and phone number.
The Book Now button checks whether the user has entered the required details.
The project uses JavaScript DOM to update the services and total amount dynamically.
I used CSS to create the layout and make the webpage look clean.
I tested the project in the browser to check that the buttons and booking form work properly.
