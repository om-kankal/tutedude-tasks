# Task 24 - ReactJS Hello World

## Project
A basic React application that displays **Hello, World!** on the screen.

## Files
- `index.html`
- `src/main.jsx`
- `src/index.css`
- `vite.config.js`
- `package.json`

## How to run
1. Open the project folder in VS Code.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown by Vite in the browser.

`node_modules` is intentionally not included in the ZIP, as required by the assignment.
